# TAO 的外贸学堂

面向中国工厂老板和外贸新人的免费外贸自学与知识速查网站。

不绕术语，从一只保温杯的真实业务逻辑开始——沿着 8 个订单节点走通第一笔出口，再用 16 个专题随时查答案。

## 网站结构

| 页面 | 路径 | 内容 |
|------|------|------|
| 首页 | `/` | 两大学习入口导航 |
| 外贸从 0 到 1 | `/learn` | 8 步案例路线图（保温杯出口订单） |
| 专题详情 | `/learn/[slug]` | 单步详解：角色、核对清单、常见错误 |
| 外贸进阶 | `/topics` | 16 个专题，按类别分组 |
| 专题详情 | `/topics/[slug]` | 白话解释、可视化图解、案例应用、来源 |
| 外贸笔记 | `/notes` | 短篇笔记，聚焦常见踩坑 |
| 笔记详情 | `/notes/[slug]` | 完整笔记正文 |
| 知识搜索 | `/search` | 按关键词搜索专题 |
| 术语表 | `/glossary` | 浏览全部外贸术语 |

## 技术栈

- **框架**: Next.js 16 (App Router) + vinext
- **样式**: Tailwind CSS 4 + 自定义手写 CSS
- **图标**: lucide-react
- **部署**: Cloudflare Workers (vinext)
- **数据库**: Cloudflare D1 + Drizzle ORM（预留，当前内容为静态数据）

## 本地开发

```bash
# 安装依赖
npm run install:ci

# 启动开发服务器（默认端口 5173）
npm run dev

# 构建生产产物
npm run build

# 本地预览生产构建
npm start
```

## 内容架构

所有学习内容以 TypeScript 数据模块形式组织在 `lib/content.ts` 中：

- `topics` — 16 个进阶专题（贸易术语、付款、单证、退税等）
- `steps` — 8 步出口订单路线图
- `notes` — 外贸笔记短文
- `glossary` — 术语表
- `caseFacts` — 案例基本参数（虚构教学案例）

页面组件位于 `components/learning-ui.tsx`，路由页面在 `app/` 目录下。

## 内容特点

- **教学案例**: 以宁波澄川不锈钢制品厂（虚构）向德国出口 2,000 个保温杯为案例，贯穿 8 个步骤
- **可视化**: Incoterms 11 项术语交互对比、付款流程图、运输路线图
- **来源标注**: 每个专题标注官方来源链接与核验日期
- **免责声明**: 内容为通识学习，不替代海关、税务、银行等专业个案意见
